# Pre-registration (T12): what the locking dictionary can and cannot say before the measurements

Written 2026-09-02, before any of the named measurements has a published sign at the stated significance.

T07's testable dictionary (c = P, γ5 = T) fixes **relative** signs only:

- P1. The sign of the leptonic CP phase δ_CP, once measured at ≥ 3σ, is predicted to be **the same bit** as the K-type
  sign already fixed by (K_L charge asymmetry, baryon excess). The dictionary does not predict which value that bit
  takes for δ_CP, because the map from "one bit" to a specific observable's sign needs a convention (the sign of the PMNS
  phase relative to the CKM phase is not fixed by any locking here). **Honest status: P1 is a consistency statement, not
  an absolute prediction. It is falsified only by a demonstration that δ_CP's sign is an independent physical choice,
  which no single measurement can provide.**
- P3. The relative signs of two EDMs (electron, neutron) are predicted **fixed**. Which relative sign is not predicted
  (the lift sign θ is unresolved). **Falsifier: two measured EDM signs whose ratio is shown to be an independent
  parameter across a family of measurements.** This requires theory input to separate operator contributions and is
  remote.
- P4. Exclusions are absolute and already decidable: no CP asymmetry may be read as the chirality row, no handedness as
  the time row. This is a rule for future modules, not a measurement.

Conclusion: no module T12 is written, because no absolute sign prediction exists. This file is the record of that fact so
that a later claim of a "pre-registered prediction" cannot be made retroactively.

## Correction (later on 2026-09-02): the relative-sign statements above are empty too

The seat tested its own proposal. Every quantity the dictionary was said to fix — the relative sign of two K-type
asymmetries (P1), of two W-type handedness signs (P2), of two EDMs (P3) — is the product of two signs of the same CPT
type, hence of type (ε_P, ε_C, ε_T) = (+, +, +): EVEN. EVEN quantities are dynamical and lie in the image of no
dictionary (T07 now checks this). So the dictionary fixes no relative sign either; P1–P3 are withdrawn, and P4 is CPT's
own bookkeeping, not a prediction.

## T17: the beta-odd bit (2026-09-02)

After sweeping the record (B303, B1224, B1226, L192), the seat found a different kind of prediction — not a relative
sign, but a **type assignment**. The object has exactly one β-odd output: the Chern-Simons invariant, which is odd under
both c and γ₅ (E-type in the dictionary). Amphichirality forces it to 2-torsion: CS ∈ {0, 1/2} mod 1. Under the
dictionary c = P, γ₅ = T, the E-type SM parameter is θ̄_QCD.

**Prediction (T17):** θ̄_QCD ∈ {0, π}. The object m004 sits at CS = 0, so under the dictionary θ̄_QCD = 0 (strong CP
conserved). The K-type weak CP phases (δ_CKM, δ_PMNS) are free bits, not fixed by the object.

**Bite:** of the first 594 chiral one-cusped census manifolds, exactly 1 (m004 itself) sits at a 2-torsion CS value.
A generic chiral manifold would predict a generic θ̄_QCD, which contradicts the current experimental bound |θ̄| < 10⁻¹⁰.

**Falsifier:** a measurement of θ̄_QCD at a value other than {0, π}, or a theoretical demonstration that the dictionary
c = P, γ₅ = T is the wrong identification. The current bound is consistent with T17 but does not test it (it is also
consistent with θ̄ = 0 for dynamical reasons, as in axion models).

This is the tree's one falsifiable particle-physics statement. It is a different claim from the withdrawn P1–P3: those
were relative signs within a CPT family (proved empty); this is a type assignment (E-type → θ̄_QCD) plus a value
(2-torsion → {0, π}) from the object's own Chern-Simons invariant.
