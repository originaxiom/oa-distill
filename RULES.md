# Rules of this tree

1. **Sweep before absence.** No file says "nothing does X" without a recorded search of the source it is about.
2. **State the comparison class.** A property of the object is a value that varies across the class the statement
   ranges over. Every module names its class.
3. **Compute the instrument's image first.** Before an instrument's output is read as a property of the object, the
   module computes what the instrument can output over the class. One element: no information about the object.
   Constant on the commensurability class: information about the class only.
4. **Choices are axioms and are priced.** Anything not forced by the previous modules is entered in `AXIOMS.md` with
   the alternative that was discarded.
5. **No number without an error bar and a date before the measurement.** Predictions are written down before the data.
6. **A script proves; prose states.** Every statement has a script whose output the test freezes.
