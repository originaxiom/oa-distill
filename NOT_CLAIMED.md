# What this tree does not claim

- That the object selects E6, E8, or any Lie algebra. T05 shows the instrument that produced those labels can emit
  nothing else on hyperbolic manifolds, and that the label is constant on a 14-member commensurability class.
- Any gauge group, any number of generations, any hypercharge, any chirality mechanism, any compact real form.
- Any dimensionful number, any mixing angle, any coupling, any mass.
- That the object's mirror is physical parity. T07 enters that as a dictionary (A8) tested by its consequences.
- That the 3d theory at the fork (T06) is, or leads to, the Standard Model. It is a 3d N = 2 theory of the object.
- Anything about the founding axiom A0. No theorem here uses it.
